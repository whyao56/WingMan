把聊天记录交给大模型记忆，通话时实时听懂对方，然后告诉你**该怎么回**。

这一版是照着四位使用反馈逐条改的。查下来**其中两条不是「体验问题」，是真 bug**
—— 一个让人永远连不上云模型，一个让每个页面的文字都挤成一列。

---

## 这一版修了什么

### 1. 「云大模型填了也连不上」→ 预设里的模型名已经过期

界面上一键预设填的 DeepSeek 模型名是 `deepseek-chat`，而它已在 **2026-07-24 被官方下线**。
照着预设点，请求必然失败 —— 但界面上看不出「这个预设已经不能用了」。

现在换成当前可用的两档，点一下即可切换：

- `deepseek-flash`（V4.1-Flash）—— 快、便宜，日常对话够用
- `deepseek-v4-pro` —— 推理更强，推演走向时更稳

顺带补了两件事：

- **退役模型名检测**：读到旧名字当场提示并给一键替换（也覆盖「以前配过、现在突然连不上」的情况）；
- **失败不再只丢一句 HTTP 报错**：按 401 / 403 / 404 / 429 / 模型名 / 超时分别给出
  「可能是什么原因 + 下一步点哪」。

### 2. 「字体排版挤在一起」→ 两个同名 CSS 类在互相覆盖

`.sub` 这个类名同时被用在两处：**各页面的副标题段落**，和**通话页的字幕行**。
字幕行定义了 `display:grid; grid-template-columns:66px 1fr`，CSS 后定义者胜 ——
于是**每个页面的副标题都被压成 66px 宽的一列**，一个词换一行。

两处单独看都没毛病，控制台也不报错，只有把页面真正渲染出来才看得见。
字幕行现已改名 `.cap`，并加了守卫测试：CSS 顶层类名一旦重复，测试直接失败。

### 3. 「太 AI 味」→ 整体视觉重做

「AI 味」其实有很具体的特征，之前基本全踩了：深色底 + 紫蓝渐变、符号堆砌
（`◎ ◈ ↧ ◉ ✚ ⚙`）、十来种字号混用。

现在改成：**浅色中性灰阶 + 单一强调色**（靛蓝）；字号收成 12 / 13 / 14.5 / 15.5 / 21 五档，
正文行高 1.7；间距统一走 8 / 12 / 16 / 24 / 32 的节奏；侧栏图标从混用符号换成统一线性 SVG。

### 4. 新手友好

指挥台顶部新增「三步卡」：**接上大模型 → 导入聊天记录 → 开始分析**，
按钮直达对应页面，两步都齐之后整块自动收起；记忆页的事实归属 `peer` / `me`
显示成「对方」/「我」；连通失败统一成「为什么 + 怎么办」的结构。

## 怎么用（3 步）

1. 把 zip **解压到任意位置**（桌面、D 盘都行，路径有中文也没关系）
2. 双击 `WingMan.exe`
3. 界面打开后 →「自检」页，那里会逐条列出还没配好的项，配好一项变绿一项

> ⚠️ **不要只把 `WingMan.exe` 单独拖出来运行。** 旁边的 `_internal` 文件夹是程序本体的一部分，
> 少一个文件都起不来。要挪位置就整个文件夹一起挪。

第一次打开提示「还有 N 项没配好」是正常的 —— 默认用的是内置演示引擎（Mock），
它跑的是固定规则、**不是真实智能**。接真模型：界面 →「设置」→ 点一个服务商预设
（会帮你把地址和模型名填好），再粘上你自己的 API Key，点「测试连通」。
支持一切 OpenAI 兼容协议的服务，也支持 Ollama 本地模型。

## 第一次打开可能遇到

**Windows 提示「已保护你的电脑」/ SmartScreen 拦截**
这是**没有花钱买代码签名证书**的正常现象，不是检测到病毒。点「更多信息」→「仍要运行」。
不放心可以先看源码：本仓库全部代码开放，你手上的 exe 就是它打的包。

**数据存在哪？**
`%LOCALAPPDATA%\WingMan\`（即 `C:\Users\你的用户名\AppData\Local\WingMan`）。
聊天记录、画像、设置、日志都在这里。**换个位置解压程序，数据不会丢**——程序和数据是分开存的。
卸载 = 删掉程序文件夹 + 删掉上面那个数据目录。

**双击了没反应？**
在命令行里跑一次：`WingMan.exe --check`
它会直接告诉你缺什么、下一步做什么，报告同时写进**数据目录**的
`%LOCALAPPDATA%\WingMan\logs\selfcheck.txt`（注意是数据目录，不是程序目录）
—— 可以直接把这份文件发给别人帮你看。
打包版没有控制台，所以出错时不会弹窗 —— 这个自检入口就是为这种情况准备的。

**标准版提示「没有内置语音识别库」**
这不是故障。标准版本来就没有语音引擎，去「设置 → 语音识别」换成「云 ASR」并填好接口地址即可。
想要开箱即用的本地语音，下完整版。

## 关于构建的可复现性

**打包这一步是确定的**：安装包由仓库里的
[`scripts/make_release.py`](https://github.com/whyao56/WingMan/blob/main/scripts/make_release.py)
生成，它把时间戳钉死、文件顺序排序，所以同样的代码重打一次会得到**字节相同**的 zip。

> **更正（2026-10-05 补）**：上面这句**只对「打包」这一步成立**。`dist/` 是 PyInstaller
> 生成的，那个构建**不是**逐字节确定的 —— 同一份源码连构建两次，219 个文件里有 2 个不同，
> 所以重建之后校验和必然会变。校验和的正确用途是核对**下载**是否完整、中途有没有被换过。
> 原文保留不改，因为这份说明是当时的发布记录；准确口径见 [v0.1.2 的说明](v0.1.2.md)。

（本版现已不再提供安装包，所以不再列出具体校验和。）

## 从 0.1.0 升上来

程序和数据是分开存的，**直接下新包解压覆盖旧文件夹即可**，聊天记录和设置都不会丢
（它们在 `%LOCALAPPDATA%\WingMan`）。

唯一需要你手动看一眼的：如果你之前把模型名填成过 `deepseek-chat` 或 `deepseek-reasoner`，
进「设置」页会看到一条过期提示，点一键替换就好。

## 这一版还包括

- **打包成桌面程序**：绿色免安装，目标机器不需要 Python；数据写到 `%LOCALAPPDATA%`，升级程序不丢数据
- **双通道语音采集**：系统回环（听对方）+ 麦克风（听自己）
- **内置自检**：界面「自检」页 + 命令行 `--check` / `--asr-test`，把「没反应」拆成「第几步不行」
- **中文转写修正**：本地模型以前偶尔输出繁体，现在带简体提示词，同一段音频实测置信度 0.735 → 0.787

完整清单见 [CHANGELOG.md](https://github.com/whyao56/WingMan/blob/main/CHANGELOG.md)。

## 请先知道这些限制

这个版本**能用，但还不够聪明**，说清楚免得你下载后失望：

- **默认是 Mock 演示引擎。** 不填 API Key 也能跑通全流程（导入 → 画像 → 分析 → 建议 → 推演），
  但建议内容是固定规则生成的，**不能当真实建议用**。要点在于「先把流程跑通、看懂它怎么工作」。
- **没有在真实通话中验证过。** 双通道采集、回环识别的代码路径是通的、接口是通的，
  但「边打微信语音边用它」这个真实场景没有实测过。
- **云 ASR 路线没有用真实密钥验证过。** 手里没有可用的 ASR 服务密钥。
  云大模型这轮的修复同样是按官方文档校正的，没有真实 Key 端到端跑过。
- **本地语音模型只实测过 `tiny` 与 `base` 两档**（都在打包版里跑通了「下载 → 加载 → 转写」全链路）；
  `small` / `medium` / `large-v3` 只验过下载与文件结构，没在打包版里跑过转写。
  同一句中文 5.3 秒音频实测：`tiny` 置信度 0.62 / 0.5s，`base` 0.74 / 0.8s。
  CPU 上想更准就用 `base`；速度优先就用 `tiny`。
- **没有在「干净机器」上验证过** —— 开发机本身装着 Python。
  理论上不需要 Python，但这一点请以你的实际体验为准。如果缺文件，请提 issue。
- **只做了 Windows。** macOS / Linux 请走源码路线，那条路本身是跨平台的。
- **它只给建议，不代你发消息。** 不做无人值守自动回复 —— 原因见
  [docs/COMPLIANCE.md](https://github.com/whyao56/WingMan/blob/main/docs/COMPLIANCE.md)。
