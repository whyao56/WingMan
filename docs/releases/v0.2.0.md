把聊天记录交给大模型记忆，通话时实时听懂对方，然后告诉你**该怎么回**。

这是第一个提供**免安装成品包**的版本——双击就能用，不用装 Python。

---

## 下载哪个？

| 文件 | 体积 | 适合 |
|---|---|---|
| **`WingMan-0.2.0-win64.zip`** | 30.9 MB | 先用起来。语音识别走云端（自己填接口） |
| **`WingMan-full-0.2.0-win64.zip`** | 91.3 MB | 想让**语音识别完全在本地跑**，音频一帧都不出本机 |

不确定就下**标准版**。它不装语音引擎，但聊天记录分析、人物画像、回复建议这些主要功能完全一样。

## 怎么用（3 步）

1. 把 zip **解压到任意位置**（桌面、D 盘都行，路径有中文也没关系）
2. 双击 `WingMan.exe`
3. 界面打开后 →「自检」页，那里会逐条列出还没配好的项，配好一项变绿一项

> ⚠️ **不要只把 `WingMan.exe` 单独拖出来运行。** 旁边的 `_internal` 文件夹是程序本体的一部分，
> 少一个文件都起不来。要挪位置就整个文件夹一起挪。

第一次打开提示「还有 N 项没配好」是正常的 —— 默认用的是内置演示引擎（Mock），
它跑的是固定规则、**不是真实智能**。接真模型：界面 →「设置」→ 填 `base_url` / `api_key` / `model`，
支持一切 OpenAI 兼容协议的服务，也支持 Ollama 本地模型。

## 第一次打开可能遇到

**Windows 提示「已保护你的电脑」/ SmartScreen 拦截**
这是**没有花钱买代码签名证书**的正常现象，不是检测到病毒。点「更多信息」→「仍要运行」。
不放心可以先看源码：本仓库全部代码开放，你手上的 exe 就是它打的包。

**数据存在哪？**
`%LOCALAPPDATA%\WingMan\`（即 `C:\Users\你的用户名\AppData\Local\WingMan`）。
聊天记录、画像、设置、日志都在这里。**换个位置解压程序，数据不会丢**——程序和数据是分开存的。
卸载 = 删掉程序文件夹 + 删掉上面那个数据目录。

**双击了没反应？**
在命令行里跑一次：`WingMan.exe --check`
它会直接告诉你缺什么、下一步做什么，结果同时写进程序目录的 `logs\selfcheck.txt`。
打包版没有控制台，所以出错时不会弹窗 —— 这个自检入口就是为这种情况准备的。

**标准版提示「没有内置语音识别库」**
这不是故障。标准版本来就没有语音引擎，去「设置 → 语音识别」换成「云 ASR」并填好接口地址即可。
想要开箱即用的本地语音，下完整版。

## 完整性校验

```text
68d445a2cadf3e0152fa350ae3ad4c597e7fb7d33a6d8a4eb385a54090c2a417  WingMan-0.2.0-win64.zip
c0f1a9f54542db08e294e03b615ebc2f4d11c9b5a92b08edad18ac7dd347cbbb  WingMan-full-0.2.0-win64.zip
```

Windows 上校验：

```powershell
Get-FileHash .\WingMan-0.2.0-win64.zip -Algorithm SHA256
```

这些校验和是**可复现**的：安装包由仓库里的
[`scripts/make_release.py`](https://github.com/whyao56/WingMan/blob/main/scripts/make_release.py)
生成，它把时间戳钉死、文件顺序排序，所以同样的代码重打一次会得到**字节相同**的 zip。

## 这一版做了什么

- **打包成桌面程序**：绿色免安装，目标机器不需要 Python；数据写到 `%LOCALAPPDATA%`，升级程序不丢数据
- **双通道语音采集**：系统回环（听对方）+ 麦克风（听自己）
- **内置自检**：界面「自检」页 + 命令行 `--check` / `--asr-test`，把「没反应」拆成「第几步不行」
- **中文转写修正**：本地模型以前偶尔输出繁体，现在带简体提示词，同一段音频实测置信度 0.735 → 0.787
- **体积优化**：剔除从未启用的 `hf_xet` 依赖

完整清单见 [CHANGELOG.md](https://github.com/whyao56/WingMan/blob/main/CHANGELOG.md)。

## 请先知道这些限制

这个版本**能用，但还不够聪明**，说清楚免得你下载后失望：

- **默认是 Mock 演示引擎。** 不填 API Key 也能跑通全流程（导入 → 画像 → 分析 → 建议 → 推演），
  但建议内容是固定规则生成的，**不能当真实建议用**。要点在于「先把流程跑通、看懂它怎么工作」。
- **没有在真实通话中验证过。** 双通道采集、回环识别的代码路径是通的、接口是通的，
  但「边打微信语音边用它」这个真实场景没有实测过。
- **云 ASR 路线没有用真实密钥验证过。** 手里没有可用的 ASR 服务密钥。
- **大模型只有 `tiny` 模型实测过**，`medium` / `large-v3` 未验证（体积大，CPU 上也不实用）。
- **没有在「干净机器」上验证过** —— 开发机本身装着 Python。
  理论上不需要 Python，但这一点请以你的实际体验为准。如果缺文件，请提 issue。
- **只做了 Windows。** macOS / Linux 请走源码路线，那条路本身是跨平台的。
- **它只给建议，不代你发消息。** 不做无人值守自动回复 —— 原因见
  [docs/COMPLIANCE.md](https://github.com/whyao56/WingMan/blob/main/docs/COMPLIANCE.md)。
